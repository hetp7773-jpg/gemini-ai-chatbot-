# 🤖 Gemini AI Chatbot (Web & Terminal)

Ek lightweight aur modern AI Assistant jo Google ke latest **Gemini 3.6 Flash** model aur Python standard library se chalta hai (Zero external dependencies needed!).

---

## 🌟 Features

* **🌐 Sleek Web Interface:** ChatGPT/Gemini jaisa ultra-modern dark theme, glassmorphism aesthetics, dynamic typing indicator, aur markdown support.
* **🧠 Multi-Turn Chat Memory:** Purani baatein aur context session mein yaad rakhta hai.
* **⚡ Zero Pip Installs:** Python ki built-in standard library par bana hai — koi complex library install karne ki zaroorat nahi.
* **💻 Terminal & Web:** Terminal console ya browser dono mein chal sakta hai.

---

## 🚀 Kaise Run Karein

### Option 1: Website (Web Browser) par Run Karein ⭐ (Recommended)

Terminal mein yeh command chalayein:

```powershell
py server.py
```
*(Ya `python server.py`)*

* Yeh automatically aapka browser open karega: **`http://localhost:5000`**
* Aap website par direct Gemini AI se chat kar sakte hain!

---

### Option 2: Terminal Console mein Run Karein

Agar aap terminal mein chat karna chahein:

```powershell
py t.py
```

---

## 🔑 Setup & API Key

Aapki `.env` file mein Google Gemini API Key honi chahiye:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Nayi key lene ke liye [Google AI Studio](https://aistudio.google.com/apikey) visit karein).*
